# RIGEL 1.0

Robotic arm prototype of the OSIRIS team. Technical Director: all sections.

| Folder | Content | Access |
|---|---|---|
| `Mechanics/` | CAD, drawings, mechanical design | Mechanics lead |
| `Electronics/` | schematics, PCB, harness | Electronics lead |
| `Software/` | control, perception, flight-like software notes | Software lead |
| `AIVT/` | Assembly, Integration, Verification and Test plans and logs | AIV/T lead |
| `Structures and Materials/` | load cases, FEM, material selection | Structures lead |
| `Documents/` | team-wide documents (`Conceptual Design/`, later requirements, reviews, reports) | Technical Director + all leads (read) |
| `Archive/` | superseded versions, old documents | Technical Director |

Rules: one owner per folder, nothing is deleted – move it to `Archive/` with the date in the name.
